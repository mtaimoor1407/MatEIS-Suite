# Video documentation script (4–5 minutes)

**Setup:** screen recorder (OBS or Windows Game Bar), 1080p, microphone check, browser zoom 100–110%, app open on the home page, dark mode. Do one dry run. Show every team member's name at the start.

| Time | Screen | Say |
|---|---|---|
| 0:00 | Home | "This is MatEIS, our CSC-214 project: three tools for materials engineers in one web app." Names of the team. |
| 0:20 | Phase page | "Choose a system, set composition and temperature, or click the diagram." Click a point. |
| 0:50 | Results | "The lever rule gives the phases and their amounts, with the arithmetic." Scroll to the microstructure: "0.35% carbon steel is 56% proeutectoid ferrite and 44% pearlite." |
| 1:30 | Selection | "Set constraints, choose an objective. The star is the best material; the dashed line has constant performance index." Press the strength preset. |
| 2:15 | Table and export | Click a row, then download the CSV. |
| 2:40 | Corrosion rate | Weight loss result; "rate in mm/y and mpy with a resistance rating". Then load the Tafel example and show the fit. |
| 3:30 | Galvanic | Steel + copper in seawater: "High"; change the area ratio and show the risk rise. |
| 4:00 | Protection | Generate the plan; show anode sizing; download the PDF. |
| 4:30 | Databases and guide | "Data are editable and validated; the guide lists how every requirement is met." |
| 4:50 | Close | "463 automated tests, deployed at this link. Thank you." |

Checklist: all names shown · deployed URL visible · no error messages on screen · audio clear · file size within the limit your instructor sets.
