- [ ] Run it locally (`python main.py`) and click through every module.
- [ ] Run `pytest -q` and `ruff check .` on your machine. Both must pass.
- [ ] **Verify the data** with `docs/DATA_VERIFICATION.md`: split the tables, check each value against Callister / MatWeb / CRC, tick *Verified* in the app, sign the sheet.
- [ ] Push to GitHub and check the green tick on the *Actions* tab (`docs/DEPLOYMENT.md`).
- [ ] Deploy on Render or Hugging Face Spaces; paste the link into `README.md`.
- [ ] Rehearse the demo (`docs/PRESENTATION_OUTLINE.md`) and record the video (`docs/VIDEO_SCRIPT.md`).
- [ ] Last class: bring the project on a laptop that runs locally as a backup.
